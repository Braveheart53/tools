Windows Exporter & Grafana Dashboard Integration Guide

Overview

This guide covers installing and configuring the NVIDIA GPU exporter on Windows to expose hardware metrics to Prometheus.

Prerequisites

  • Windows Server/10/11 with NVIDIA GPUs and driver installed
  • Prometheus instance running & configured
  • Administrator privileges

Step 1: Download & Extract

# Download latest release (replace version if needed)
curl -LO https://github.com/prometheus-community/nvidia_gpu_exporter/releases/download/v1.5.0/nvidia_gpu_exporter-1.5.0.windows-amd64.zip
Expand-Archive -Path nvidia_gpu_exporter-*.zip -DestinationPath C:\nvidia-exporter

Step 2: Configure & Run as Service

# Create configuration file
New-Item -Path "C:\nvidia-exporter\config.yaml" -ItemType file -Force

# Start exporter manually to verify
"C:\nvidia-exporter\nvidia_gpu_exporter.exe" --path-msi="C:\Program Files\NVIDIA Corporation\NVSMI\nvidia-smi.msi"

# Or register as Windows Service for persistence
New-Service -Name "NvidiaGPUExporter" -BinaryPathName "C:\nvidia-exporter\nvidia_gpu_exporter.exe" -DisplayName "NVIDIA GPU Exporter" -StartupType Automatic
Start-Service "NvidiaGPUExporter"

Step 3: Verify Metrics

Open a browser and visit: http://localhost:9835

Confirm key metrics are exposed:

  • nvidia_smi_utilization_gpu_ratio
  • nvidia_smi_memory_used_bytes
  • Power, temperature, and ECC metrics
ℹ️ Note: Ensure your prometheus.yml includes a scrape job targeting localhost:9835. Metrics will only appear in Prometheus after the first successful scrape cycle.

Overview

Visualize GPU metrics in Grafana using the official NVIDIA GPU Exporter dashboard. This page covers data source configuration, dashboard import, and customization.

Prerequisites

  • Grafana installed and accessible via web browser
  • Prometheus data source configured in Grafana
  • GPU exporter running and exposing metrics (as covered in Page 1)

Step 1: Add Prometheus as a Data Source

  1. Open Grafana and navigate to Configuration > Data Sources.
  2. Click Add data source and select Prometheus.
  3. Set the URL to your Prometheus instance (e.g., http://localhost:9090).
  4. Click Save & Test to verify connectivity.

Step 2: Import a GPU Dashboard

The most widely adopted option is the official community dashboard (ID: 12574).

  1. In Grafana, go to Create > Import.
  2. Paste 12574 into the import field, or upload a valid JSON dashboard file.
  3. Under Settings, map the dashboard to the Prometheus data source configured in Step 1.
  4. Click Import.

Step 3: Configure & Verify Panels

Once imported, panels will automatically query exposed metrics. Key panels typically include:

  • GPU Utilization: Queries nvidia_smi_utilization_gpu_ratio
  • Memory Usage: Visualizes nvidia_smi_memory_used_bytes vs allocated memory
  • Temperature & Power: Tracks thermal output and power draw per GPU
ℹ️ Troubleshooting: If panels show No Data, verify:
  • The exporter service is running (Get-Service NvidiaGPUExporter)
  • Prometheus scrape job includes localhost:9835
  • Grafana time range covers the last 5–10 minutes

Step 4: Customize & Multi-GPU Support

  1. Click any panel title > Edit.
  2. Modify the PromQL query to target specific GPUs (e.g., nvidia_smi_utilization_gpu_ratio{device=~"0|1|2"} for a 3-GPU system).
  3. Adjust panel thresholds, legends, and display units.
  4. Click Apply to save changes.

✅ Pipeline Complete: You now have a fully functional monitoring stack: Windows Exporter → Prometheus → Grafana. You can track real-time GPU health, utilization, and memory consumption directly in your Grafana instance.

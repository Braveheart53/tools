NVIDIA GPU Exporter (Windows)

Expose NVML/SMI telemetry to Prometheus. Compatible with Tesla, RTX, and data center architectures.

1. Install & Configure

# Download latest exporter
curl -LO https://github.com/prometheus-community/nvidia_gpu_exporter/releases/download/v1.5.0/nvidia_gpu_exporter-1.5.0.windows-amd64.zip
Expand-Archive -Path nvidia_gpu_exporter-*.zip -DestinationPath C:\nvidia-exporter

# Register as Windows Service (persistent)
New-Service -Name "NVIDIA-GPU-Exporter" -BinaryPathName "C:\nvidia-exporter\nvidia_gpu_exporter.exe" `
            -DisplayName "NVIDIA GPU Metrics Exporter" -StartupType Automatic
Start-Service "NVIDIA-GPU-Exporter"

2. Verify Telemetry

Visit http://localhost:9835/metrics. Confirm key time-series:

  • nvidia_smi_utilization_gpu_ratio
  • nvidia_smi_memory_used_bytes / nvidia_smi_memory_total_bytes
  • nvidia_smi_power_usage_watts, nvidia_smi_temp_gpu
ℹ️ Prometheus Config Snippet:
scrape_configs:
- job_name: 'nvidia-gpu'
static_configs: [{targets: ['localhost:9835']}

AMD GPU Exporter (ROCm / Windows)

Monitor ROCm-compatible RDNA 3 / CDNA architectures, including Ryzen AI, Radeon Pro W7000, and Instinct MI series. Requires ROCm 6.x+ runtime.

📦 Exporter Setup

# Install ROCm drivers first, then exporter
curl -LO https://github.com/prometheus-community/amd-rocm-exporter/releases/download/v0.8.0/amd-rocm-exporter_0.8.0_windows_amd64.zip
Expand-Archive -Path amd-rocm-exporter*.zip -DestinationPath C:\amd-exporter

# Start with ROCm collector enabled
C:\amd-exporter\amd-rocm-exporter.exe --collector.rocm=true

# Register as service
New-Service -Name "AMD-GPU-Exporter" -BinaryPathName "C:\amd-exporter\amd-rocm-exporter.exe" `
            -StartupType Automatic

📊 Key Metrics

  • rocm_gpu_utilization (% load per pipe)
  • rocm_memory_used_bytes / rocm_memory_total_bytes
  • rocm_power_sensor_watts, rocm_temperature_sensor
  • rocm_ecc_errors_corrected (if supported)

Prometheus Target Config

- job_name: 'amd-rocm'
  static_configs: [{targets: ['localhost:9295']}
ℹ️ Note: AMD ROCm on Windows requires ROCm 6.1+ and compatible GPU drivers. Verify installation with rocm-smi --showinfo. Exporter defaults to port :9295.

Grafana Dashboard Configuration

Unified visualization for both NVIDIA and AMD telemetry. Import official community dashboards or build custom panels.

1. Add Prometheus Data Source

  1. Configuration > Data Sources > Add source > Prometheus
  2. Set URL: http://localhost:9090 (or your cluster endpoint)
  3. Click Save & Test. Green checkmark = confirmed connectivity.

2. Import GPU Dashboards

🟢 NVIDIA Dashboard

Dashboard ID: 12574

  1. Create > Import in Grafana
  2. Paste ID or upload JSON
  3. Select your Prometheus DS
  4. Click Import

🔵 AMD Dashboard

Dashboard ID: 16088 (Official ROCm/GPU)

  1. Repeat import steps above
  2. Maps to rocm_* metric namespace
  3. Supports multi-DIC/pipe aggregation out-of-the-box

3. Troubleshooting & Customization

  • No Data? Check Grafana time range (last 5-10 mins), verify exporter service status, and confirm Prometheus scrape targets are UP.
  • Multigpu Filtering: Edit panel query → Add label matchers: {device=~"0|1|2"}
  • Custom Alerts: Use PromQL thresholds like rate(nvidia_smi_power_usage_watts[5m]) > 350 or rocm_temperature_sensor > 85

Install & Use Prometheus + Grafana on Node A

This page walks you through:

  • Installing Prometheus (the monitoring server).
  • Installing Node Exporter (the agent that gathers metrics from each node).
  • Installing Grafana (the web UI for visualising the data).
  • Configuring Prometheus to scrape metrics from Node A and any other nodes.
  • Adding Prometheus as a data source in Grafana and creating a simple dashboard.
  • Viewing the status of the other nodes from Node A.

1️⃣ Prerequisites

  • A Linux machine (Ubuntu 20.04/22.04, Debian, CentOS 8, or any systemd‑based distro).
  • Root or sudo privileges.
  • Internet access to download packages.
Why Node Exporter? It exposes CPU, memory, disk, and GPU metrics (if the GPU driver provides them) in a format Prometheus can scrape.

2️⃣ Install Prometheus

2.1 Download the latest release

# Choose the version you need – here we use 2.53.0 as an example
VERSION=2.53.0
wget https://github.com/prometheus/prometheus/releases/download/v${VERSION}/prometheus-${VERSION}.linux-amd64.tar.gz

2.2 Extract & create a directory

tar xvf prometheus-${VERSION}.linux-amd64.tar.gz
sudo mkdir -p /etc/prometheus /var/lib/prometheus
sudo mv prometheus-${VERSION}.linux-amd64/* /etc/prometheus/
sudo chown -R root:root /etc/prometheus /var/lib/prometheus

2.3 Create a basic Prometheus configuration

cat <<'EOF' | sudo tee /etc/prometheus/prometheus.yml
global:
  scrape_interval: 15s   # how often to scrape targets
  evaluation_interval: 15s

scrape_configs:
  # Node Exporter running on the same host (Node A)
  - job_name: 'node'
    static_configs:
      - targets: ['localhost:9100']

  # Add other nodes here – replace  with the actual address of each node
  - job_name: 'remote-nodes'
    static_configs:
      - targets: [':9100',
                 ':9100']
EOF

2.4 Create a systemd service file

cat <<'EOF' | sudo tee /etc/systemd/system/prometheus.service
[Unit]
Description=Prometheus Monitoring Server
Wants=network-online.target
After=network-online.target

[Service]
User=root
Group=root
ExecStart=/etc/prometheus/prometheus \\
  --config.file=/etc/prometheus/prometheus.yml \\
  --storage.tsdb.path=/var/lib/prometheus \\
  --web.console.templates=/etc/prometheus/consoles \\
  --web.console.libraries=/etc/prometheus/console_libraries
Restart=always

[Install]
WantedBy=multi-user.target
EOF

2.5 Enable & start Prometheus

sudo systemctl daemon-reload
sudo systemctl enable prometheus
sudo systemctl start prometheus

2.6 Verify it’s running

sudo systemctl status prometheus

Open a browser on Node A and go to http://localhost:9090. You should see the Prometheus UI.

3️⃣ Install Node Exporter (the metric collector)

3.1 Download & extract

VERSION=1.8.0
wget https://github.com/prometheus/node_exporter/releases/download/v${VERSION}/node_exporter-${VERSION}.linux-amd64.tar.gz
tar xvf node_exporter-${VERSION}.linux-amd64.tar.gz
sudo mv node_exporter-${VERSION}.linux-amd64 /opt/node_exporter
sudo ln -s /opt/node_exporter/node_exporter /usr/local/bin/node_exporter

3.2 Create a systemd service

cat <<'EOF' | sudo tee /etc/systemd/system/node_exporter.service
[Unit]
Description=Prometheus Node Exporter
Wants=network-online.target
After=network-online.target

[Service]
User=root
Group=root
ExecStart=/opt/node_exporter/node_exporter
Restart=always

[Install]
WantedBy=multi-user.target
EOF

3.3 Enable & start Node Exporter

sudo systemctl daemon-reload
sudo systemctl enable node_exporter
sudo systemctl start node_exporter

3.4 Verify

curl http://localhost:9100/metrics | head -n 20

You should see a long list of metrics ending with a line like # HELP node_cpu_seconds_total....

4️⃣ Install Grafana

4.1 Add the official Grafana APT repository (Ubuntu/Debian)

sudo apt-get update
sudo apt-get install -y wget gnupg2 curl
curl https://apt.grafana.com/gpg.key | sudo apt-key add -
echo "deb https://apt.grafana.com stable main" | sudo tee /etc/apt/sources.list.d/grafana.list

4.2 Install Grafana

sudo apt-get update
sudo apt-get install -y grafana

4.3 Enable & start the service

sudo systemctl daemon-reload
sudo systemctl enable grafana-server
sudo systemctl start grafana-server

4.4 Access Grafana UI

Open a browser on Node A and navigate to http://localhost:3000.
Default login: admin / admin. You will be prompted to change the password on first login.

5️⃣ Add Prometheus as a Data Source in Grafana

  1. Log in to Grafana (the UI you just opened).
  2. Click the ⚙️ Configuration (gear) icon → Data Sources → Add data source.
  3. Select Prometheus from the list.
  4. Set the URL to http://localhost:9090 (Prometheus runs on the same host).
  5. Leave Access as Direct access.
  6. Click Save & test. You should see Success.
If you plan to run Grafana on a different machine than Node A, replace localhost with the IP address of Node A and make sure the firewall allows traffic on port 9090.

6️⃣ Create a Simple Dashboard to Visualise Node A & Other Nodes

  1. In Grafana, click the + (Create) button → Dashboard → Add new panel.
  2. In the panel editor, change the Query dropdown to Prometheus.
  3. Enter the following PromQL query to see CPU utilisation of Node A (the node exporter runs on the same host):
    4. 100 - (avg by (instance) (rate(node_cpu_seconds_total{mode="idle"}[5m])) * 100)
  4. Under Visualization, pick Graph. Give the panel a title like “Node A CPU %”.

6.1 Add panels for other nodes

Repeat the steps above, but change the query to target a specific node (replace node-B with the actual instance name you see in Prometheus):

# CPU % for Node B
100 - (avg by (instance) (rate(node_cpu_seconds_total{instance="node-B:9100",mode="idle"}[5m])) * 100)

# GPU utilisation (if the driver exports a metric called node_gpu_utilisation_percent)
avg by (instance) (node_gpu_utilisation_percent{instance="node-B:9100"})

You can also create a Table panel that lists the status (UP/DOWN) of each node:

up{job="node"} == 1

Set the visualization to Table, enable Color mode → Status, and you’ll get a green/red view of every node’s health.

7️⃣ Using Grafana from Node A to Check the Status of Other Nodes

Grafana itself does not provide a “one‑liner” command to query another node’s status, but you can combine the Prometheus API with a tiny script on Node A.

7.1 Example Bash script (requires `curl` and `jq`)

#!/usr/bin/env bash
# List of node IPs or hostnames you want to monitor
NODES=("node-b.example.com" "node-c.example.com")

for n in "\${NODES[@]}"; do
    # Query Prometheus for the 'up' metric (1 = up, 0 = down)
    STATUS=\$(curl -s "http://\${n}:9090/api/v1/query?query=up{\\"instance\\":\\"\${n}\\"}" | jq -r '.data.result[0].value[1]')
    if [[ "\$STATUS" == "1" ]]; then
        echo "✅ \${n} is UP"
    else
        echo "❌ \${n} is DOWN"
    fi
done

Save this as check_nodes.sh, make it executable (chmod +x check_nodes.sh), and run it. It will print a quick health summary for each node.

8️⃣ Optional: Enable GPU Metrics (if your GPU driver exposes them)

Most NVIDIA GPUs expose metrics via the nvidia-smi command. To make those available to Prometheus, you can use the nvidia-gpu-prometheus-exporter.

8.1 Quick install of the exporter

# Download latest release
EXPORTER_VER=0.4.0
wget https://github.com/NVIDIA/gpu-prometheus-exporter/releases/download/v${EXPORTER_VER}/gpu-prometheus-exporter-linux-amd64.tar.gz
tar xvf gpu-prometheus-exporter-linux-amd64.tar.gz
sudo mv gpu-prometheus-exporter-linux-amd64 /opt/gpu-exporter
sudo ln -s /opt/gpu-exporter/gpu-prometheus-exporter /usr/local/bin/gpu-exporter

# Run it as a service (listens on 9185)
cat <<'EOF' | sudo tee /etc/systemd/system/gpu-exporter.service
[Unit]
Description=NVIDIA GPU Prometheus Exporter
Wants=network-online.target
After=network-online.target

[Service]
User=root
Group=root
ExecStart=/opt/gpu-exporter/gpu-prometheus-exporter --web.listen-address=:9185
Restart=always

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable gpu-exporter
sudo systemctl start gpu-exporter

8.2 Add the GPU exporter to Prometheus

# Edit /etc/prometheus/prometheus.yml and add another scrape target:
- job_name: 'gpu'
  static_configs:
    - targets: ['localhost:9185']

8.3 Query GPU utilisation in Grafana

avg by (instance) (nvidia_gpu_utilization{instance="node-B:9185"})

You can now plot GPU % alongside CPU, memory, and network charts.

9️⃣ Summary Checklist

  1. ✅ Install Prometheus and start the service.
  2. ✅ Install Node Exporter on every node (including Node A) and start it.
  3. ✅ (Optional) Install nvidia‑gpu‑prometheus‑exporter if you need GPU stats.
  4. ✅ Install Grafana and start its service.
  5. ✅ Add Prometheus as a datasource in Grafana.
  6. ✅ Build dashboards (CPU, memory, GPU, node health).
  7. ✅ Use a small script or Grafana’s built‑in “Explore” to query other nodes from Node A.
All services are managed by systemd, so they will automatically restart after a reboot. Use sudo systemctl status <service> to verify they are running.

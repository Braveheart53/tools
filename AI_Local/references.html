What the confidence classes mean

A page that mixes a project's own reference manual with a commercial model card ought to say which is which, because the two age very differently.

Sourcing-confidence classes used in the table above, with how many references fall into each.
ClassMeaningCount
primaryNormative or first-party specification24
vendorFirst-party but commercial; revised without notice10

The practical consequence. A primary reference describes behaviour that changes on a release boundary, with a changelog. A vendor reference — every model card in this list — is revised in place: a tag's size changes when it is requantised, and tags are added and withdrawn without any record. Anything cited to a model card should be re-read before hardware is bought on the strength of it.

Figures with no citation

Some numbers on these pages are not in any source, because no source publishes them. They are planning estimates for this class of hardware and they are listed here so they are not mistaken for cited facts. Each is stated as a range at its point of use, and the equation block that consumes it names it as an estimate.

Uncited planning estimates used across the set, with the value, where it is used, and how to replace it with a measurement.
QuantityValue usedUsed inHow to measure it
GGUF container overhead \(\varepsilon\) 0.03 – 0.08 Weight footprint Compare a published tag size against \(P b_{q}/8\) for a model whose parameter count and quantisation you know
Throughput realisation factor \(\eta\) 0.5 – 0.8 Bandwidth ceiling scripts/probe_model_throughput.py, then divide the measured rate by the computed bound
Runtime VRAM reservation \(V_{\text{rt}}\) 0.8 – 1.5 GB Context budget, layer offload nvidia-smi with a model loaded, minus the published weight size
Peak compiler resident set \(M_{\text{job}}\) 1.5 – 2.5 GB Parallel job count Watch peak working set during a single-job build of your heaviest translation unit
Exporter series counts ~1500 / ~120 / ~30 Prometheus ingest rate Query prometheus_tsdb_head_series on your own server
Model architecture placeholders \(n_{\ell}=48,\ n_{kv}=8,\ d_{h}=128\) plausible shape only 24 GB worked fit ollama show <tag>

Why they are published at all. An equation with no numbers in it cannot be checked. These ranges make the worked examples concrete enough to verify the algebra and to sanity-check a result, which is worth more than leaving the examples symbolic — provided the estimates are labelled, which is the purpose of this table.

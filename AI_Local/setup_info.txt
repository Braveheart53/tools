# Building amd_smi_exporter in WSL 2 (Ubuntu 24.04 Noble)

This guide fixes the `cstdint` and GPG errors for **Ubuntu 24.04**. It ensures the C++ build tools and AMD ROCm libraries are correctly mapped for the Noble Numbat release.

### 1. Fix DNS and GPG Key
If you encounter "Something wicked" resolution errors, ensure your `wget` command uses the `repo.` subdomain.

```bash
# Ensure the keyrings directory exists
sudo mkdir -p /etc/apt/keyrings
sudo chmod 0755 /etc/apt/keyrings

# Download the official AMD ROCm GPG key
wget -qO - https://radeon.com | gpg --dearmor | sudo tee /etc/apt/keyrings/rocm.gpg > /dev/null
```

### 2. Register Repository & Install Dependencies
For **Noble (24.04)**, we point specifically to the `noble` distribution. This step also installs `build-essential` to provide the standard C++ headers (like `cstdint`) that caused your previous build failure.

```bash
# 1. Remove any old/broken rocm.list files
sudo rm -f /etc/apt/sources.list.d/rocm.list

# 2. Add the ROCm 6.2 repository for NOBLE
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/rocm.gpg] https://radeon.com noble main" | sudo tee /etc/apt/sources.list.d/rocm.list
sudo apt update && sudo apt install dirmngr --install-recommends -y
sudo mkdir -p /root/.gnupg
sudo chmod 700 /root/.gnupg
sudo HOME="$HOME" gpg --no-default-keyring --keyring /etc/apt/keyrings/rocm.gpg --keyserver hkp://keyserver.ubuntu.com:80 --recv-keys 9386B48A1A693C5C
sudo gpg --no-default-keyring --keyring /etc/apt/keyrings/rocm.gpg --keyserver hkp://://ubuntu.com --recv-keys 9386B48A1A693C5C
# 3. Update and Install
sudo apt update
sudo apt install python3-setuptools python3-wheel -y
sudo apt install amd-smi-lib -y
sudo apt install build-essential -y
export CGO_CFLAGS="-I/opt/rocm/include"
export CGO_LDFLAGS="-L/opt/rocm/lib"
export LD_LIBRARY_PATH=/opt/rocm/lib:$LD_LIBRARY_PATH
```

### 3. Compile the Exporter
sudo sudo git clone https://github.com/amd/amd_smi_exporter.git
cd amd_smi_exporter/src
sudo apt update
sudo apt install build-essential g++ libstdc++-12-dev -y
sudo apt install build-essential g++ g++-12 -y
sudo apt install -y build-essential g++ libc6-dev

With the `noble` libraries and C++ headers installed, compile the Go binary with the correct environment flags.

```bash

unset CC
unset CXX
unset CGO_CFLAGS
unset CGO_CXXFLAGS
unset CGO_LDFLAGS

# verify defaults
go env CC CXX CGO_CFLAGS CGO_CXXFLAGS

# Clear old failed build artifacts
make clean
go clean -cache

# Build using explicit paths for the Noble ROCm headers
sudo CGO_CFLAGS="-I/opt/rocm/include" CGO_LDFLAGS="-L/opt/rocm/lib" make

sudo env CGO_ENABLED=1 \
         CXX=g++ \
         CC=gcc \
         CGO_CFLAGS="-I/opt/rocm/include -I/opt/rocm/include/amd_smi" \
         CGO_CXXFLAGS="-I/opt/rocm/include -I/opt/rocm/include/amd_smi -std=c++17" \
         CGO_LDFLAGS="-L/opt/rocm/lib -lstdc++" \
         go build -o amd_smi_exporter main.go cpu_data.go


```

1. **Help Menu**: Run `./amd_smi_exporter --help` to verify the binary is functional.
2. **GPU Visibility**: Run `amd-smi` to ensure the WSL 2 kernel can communicate with your physical AMD GPU.

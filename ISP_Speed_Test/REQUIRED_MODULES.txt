Third-party — install with any one of:
  uv    : uv sync            (pyproject.toml + .python-version; add --extra fallback for speedtest-cli)
  mamba : mamba env create -f environment.yml
  pip   : pip install -r requirements.txt

module          min version   tested    purpose
qtpy            2.4           2.4.3     Qt abstraction layer (script sets QT_API=pyside6)

pyqtgraph       0.13.3        0.14.0    live plots (3x2 grid, DateAxisItem, ErrorBarItem)
numpy           1.26          2.5.2     array maths / round statistics / Veusz arrays
h5py            3.10          3.16.0    writes the native Veusz .vszh5 (HDF5) document
speedtest-cli   2.1.3         2.1.3     OPTIONAL fallback back-end. NOT recommended next to the Ookla CLI:
                                        it installs a same-named `speedtest`/`speedtest.exe` shim in the
                                        env's bin/Scripts folder that shadows the real CLI on PATH.

Standard library only (no install): argparse, csv, dataclasses, datetime, json, logging,
math, os, platform, random, re, shutil, signal, socket, sqlite3, subprocess, sys, time,
traceback, typing.

(none)           Simulated back-end          built in, for exercising the pipeline offline

Safe degradation
----------------
pyqtgraph missing  -> Plots tab shows an install hint, everything else works
h5py missing       -> Veusz export skipped with a logged error, other exports work
no back-end found  -> status bar reports it; campaign will not start
